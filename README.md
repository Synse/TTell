TTell adds slash commands and a key binding for whispering your current target as well as a slash command for re-whisper (whispers the last player whispered, same as Shift+R).

The slash commands can be used in macros and the AddOn is compatible with cross-realm battlegrounds, dungeons, and looking for raid.

## Whisper Target (Tell Target)

*   `/tt <message>`
*   `/wt <message>`

## Re-Whisper

*   `/rt <message>`
*   `/rtt <message>`
